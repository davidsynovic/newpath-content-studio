# NewPath Content Studio

## Run locally (Windows)
```
py -m pip install -r requirements.txt
py -m streamlit run content_app.py
```
NewPath Content Studio is a web tool that turns raw business notes into a full set of ready-to-publish marketing and client materials in under a minute. It’s built for NewPath Business Advisors’ voice and audience.

The problem it solves

Good advisory firms have plenty of expertise: call notes, meeting recaps, workshop transcripts, client updates. The bottleneck is turning that into consistent content. Writing a LinkedIn post, a newsletter, follow-up emails, a client handout, and a carousel from one set of notes takes hours, and it’s usually the first thing dropped when the week gets busy.

What it does

You paste notes or upload a file (PDF, Word, text, or audio and video, which it transcribes). The tool then writes:

A LinkedIn post with a strong hook and hashtags, with a character counter.
An email newsletter in a personal, story-driven style, signed by the chosen author.
A 3-email follow-up sequence (Day 0, 4, and 10) with A/B subject line options.
An executive briefing, a client handout with takeaways and a 30-day action checklist.
A 5-slide carousel, downloadable as a branded PowerPoint in NewPath colors with the company logo.

Control over voice and quality

Settings for audience (e.g., small business owners, founders stuck in day-to-day operations), tone, call to action, author name and title, and custom brand rules.
An Editorial Coach chat with one-click tweaks like “punchier,” “shorter,” and “warmer,” so drafts can be refined without starting over.
Every draft is editable in the app.
A Source Check flags any number, name, or claim that isn’t in the original notes, which lowers the risk of publishing something inaccurate under an executive’s name.

What it does for the company

Saves time: one set of notes becomes five deliverables, so a week of content takes minutes of review.
Keeps the brand consistent: the same voice and rules apply whoever uses it.
Gets more from existing work: every client conversation or workshop can become a multi-channel campaign.
Keeps people in control: drafts are starting points that a person reviews, edits, and approves.
Is easy to adopt: it runs in a web browser behind a password, with no software to install.

Honest limits

It drafts. A human should review before anything is published.
It only knows what’s in the notes you give it, and it’s told not to invent facts. Source Check is an extra safeguard, not a guarantee.
The current demo runs on a shared AI account with usage limits, which can be upgraded for regular use.
